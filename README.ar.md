# lahja-voice

[English](README.md)

يحوّل نص الكلام المنطوق (نفس ملفات بلجن `lahja` التي فيها أسطر مثل `[narrator] نص`) إلى ملفات mp3 عبر واجهة ElevenLabs للتحويل من نص إلى صوت. مهارة واحدة وسكربت بايثون واحد (3.8 فما فوق، المكتبة القياسية فقط)، ترخيص MIT.

## آمن افتراضياً

الأمر الفرعي `dry` هو تجربة جافة: يطبع عدد الأسطر والحروف، ومعرّف الصوت، والنموذج، والوجهة، وأول 80 حرفاً من كل سطر، ثم يقول إن المحاسبة بالحروف حسب خطتك في ElevenLabs وإنه لم يُرسل شيء. التجربة الجافة لا تقرأ مفتاحك ولا يفتح السكربت أي اتصال شبكة. هي تقرأ فقط ملف النص الذي تحدده، ولازم يكون ملفاً محلياً عادياً (المجلدات والأجهزة ومسارات UNC والشبكة والمسارات اللي فيها ':' تُرفض). تعرض أول 50 طلباً فقط (80 حرفاً لكل طلب) وتعدّ الباقي.

## الخصوصية: وش يطلع من جهازك ومتى

فقط عند تشغيل الأمر الفرعي `send`: نص الأسطر المنطوقة (بدون الوسوم وبدون محارف التحكم) ومعرّف الصوت واسم النموذج تروح إلى `https://api.elevenlabs.io`، والمفتاح يروح في ترويسة `xi-api-key`. المضيفان المقبولان فقط: `https://api.elevenlabs.io` وللاختبار `http://127.0.0.1:PORT`؛ والعنوان المحلي يستلم المفتاح أيضاً، فأي برنامج يسمع على ذلك المنفذ المحلي يشوفه. ما يُرسل شيء غير ذلك: لا أسماء ملفات ولا مسارات ولا بقية النص. ElevenLabs تعالج النص حسب شروطها وإعدادات خطتك. البلجن ما فيه أي تتبّع.

## التكلفة

المحاسبة بالحروف حسب خطتك. كل تجربة جافة تعرض العدد بالضبط. الخيار `--max-chars` (الافتراضي 5000) سقف للمجموع؛ يرفض السكربت (خروج 2) قبل إرسال أي شيء إذا تجاوز النص هذا السقف. راجع سعر خطتك وحصتها في elevenlabs.io.

## إنشاء مفتاح API

تسويها بنفسك، ولا أحد غيرك يتعامل مع المفتاح.

1. سجّل في elevenlabs.io.
2. افتح الملف الشخصي ثم API Keys ثم أنشئ مفتاحاً.
3. أعطه صلاحية Text to Speech فقط وحدد حداً شهرياً للحروف.
4. ضعه في متغير بيئة اسمه `ELEVENLABS_API_KEY`. في PowerShell للجلسة الحالية: `$env:ELEVENLABS_API_KEY = '...'` (ضع مفتاحك بين الاقتباسين). أو أضفه في متغيرات البيئة للمستخدم في ويندوز وأعد تشغيل الطرفية.
5. لا ترفع المفتاح إلى git ولا تلصقه في أي محادثة. السكربت يرفض خيارات مثل `--api-key` ولا يقرأ المفتاح من ملف.

## الاستخدام

```
python scripts/lahja_voice.py dry|send script.md --voice-id VOICE_ID [--model eleven_multilingual_v2] [--out DIR_or_FILE.mp3] [--tagged-only | --all-lines] [--tag REGEX] [--max-chars 5000] [--api-base URL]
```

- معرّف الصوت تلقاه في مكتبة الأصوات في ElevenLabs.
- النطاق الافتراضي: الأسطر اللي تبدأ بوسم `[tag]` إن وجدت في النص، وإلا كل الأسطر غير الفارغة. الوسم المطابق يُحذف من النص المنطوق. التعبير لازم يكون بسيطاً (بدون مراجع خلفية أو lookaround، وبدون مجموعة مكررة فيها تكرار أو `|`، وبحد أقصى 3 تكرارات مثل `*` و`+` و`{n,}`، والأعداد حتى 100) ولا يرى إلا أول 256 حرفاً من السطر. الأسطر تنقسم عند CR وLF وVT وFF وNEL وU+2028 وU+2029.
- طلب واحد لكل سطر؛ السطر الأطول من 2500 حرف يُقسَّم عند نهاية جملة إن أمكن، وإلا عند مسافة، وإلا بقطع مباشر (وقد يفصل الحرف عن علاماته). الملفات `line_001.mp3` وما بعده في مجلد جديد (الافتراضي `<اسم النص>_voice`).
- المخرجات ملفات جديدة فقط: المجلد غير الفارغ أو الملف الموجود يُرفض (خروج 2)، و`--out` لا يقبل مسارات UNC ولا ':' (إلا حرف القرص) ولا محارف تحكم ولا نقطة أو مسافة في الآخر ولا أسماء أجهزة محجوزة. كل ملف صوت يُكتب باسم مؤقت ولا يُعاد تسميته إلا بعد اكتماله؛ وإذا فشلت الكتابة الأخيرة يُحفظ الصوت المدفوع في ملف استرجاع في مجلد temp ويُطبع مساره. يتوقف عند أول خطأ.
- النص يُنظَّف من محارف التحكم والاتجاه والعرض الصفرية والمحارف غير المخصصة (وهذا يحذف ZWNJ وZWJ)، ولا يُعامل كخيارات أبداً. الوسائط اللي تشبه مفتاح API تُرفض، وكذلك أي `--voice-id` أو `--model` أو `--out` أو `--tag` أو مسار نص يحتوي مفتاحك.
- أكواد الخروج: 0 تمام، 1 خطأ، 2 رفض (السقف أو المضيف أو المخرجات الموجودة أو مفتاح في سطر الأوامر).
- `--api-base` يقبل `https://api.elevenlabs.io` أو `http://127.0.0.1:PORT` (للاختبار). التحويلات لا تُتبع أبداً. الرد لا يُحفظ إلا إذا كان `Content-Type` هو `audio/mpeg` وحجمه ≤ 50 ميجا والطول المستلم يساوي `Content-Length` (أو مجزّأ وانتهى سليماً) ويبدأ بوسم ID3 أو ترويسة إطار MPEG. الطلب الواحد حده 120 ثانية إجمالاً.

في Claude Code المهارة تعتمد مسبقاً `dry` فقط. تعرض عليك التجربة الجافة ولا تشغّل `send` إلا بعد ما تقول نعم في المحادثة؛ و`send` غير معتمد مسبقاً فيسألك Claude Code إذنك لحظتها. الخيار القديم `--send` لم يعد موجوداً ويعطي خطأ.

## الحدود

- المؤلف لم يُجرِ أي استدعاء حقيقي للواجهة قط. صيغة الطلب مبنية على التوثيق العام (`POST /v1/text-to-speech/{voice_id}` مع JSON فيه `text` و`model_id`) وغير متحقق منها؛ والرد بلا `Content-Length` وغير مجزّأ يُرفض وقد تفعله الخدمة الحقيقية.
- `dry` قد يعرض أول أسطر أي ملف نصي UTF-8 تدلّه عليه (50 سطراً كحد أقصى بطول 80 حرفاً). وجّهه لملفات النص فقط.
- لم يُصلَح: تقاطع/رابط رمزي كـ`--out` يُتبع؛ والعد بحروف بايثون، وبايثون 3.8 يعرف نسخة يونيكود أقدم.
- العد بحروف بايثون وقد تعدّ ElevenLabs بفارق بسيط.
- نطق اللهجة يعتمد على النموذج والصوت؛ اسمع قبل النشر.
